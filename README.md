# Portfolio — อภินันท์ พงษ์คำ

แฟ้มสะสมผลงานส่วนตัว จัดทำเป็นเว็บไซต์แบบ static HTML/CSS พร้อมใช้งานผ่าน GitHub Pages

## โครงสร้างเว็บไซต์
- `index.html` — หน้าแรก
- `about.html` — ประวัติส่วนตัว
- `certificates.html` — เกียรติบัตรและผลงาน
- `knowledge.html` — คลังความรู้
- `contact.html` — ช่องทางการติดต่อ
- `styles.css` — ดีไซน์และธีมของเว็บไซต์ทั้งหมด
- `script.js` — สคริปต์เมนูสำหรับหน้าจอมือถือ

## การเผยแพร่ผ่าน GitHub Pages
1. Push โค้ดทั้งหมดขึ้น branch `main`
2. ไปที่ Settings → Pages → Source เลือก branch `main` และโฟลเดอร์ `/ (root)`
3. เว็บไซต์จะเผยแพร่ที่ `https://<username>.github.io/portfolio/`
