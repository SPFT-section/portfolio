# รูปภาพ

ใส่ไฟล์รูปภาพในโฟลเดอร์นี้ตามชื่อที่ index.html เรียกใช้:

- `profile.jpg` — รูปโปรไฟล์ (ใช้ทั้งหน้า Home และ About)
- `activity-christmas.jpg` — รูปกิจกรรมร้องเพลงวันคริสต์มาส (การ์ดใหญ่ด้านซ้าย)
- `activity-campaign.jpg` — รูปกิจกรรมรณรงค์ (การ์ดเล็กด้านขวาบน)

การ์ดที่ 3 (ด้านขวาล่าง) เป็นข้อความล้วน ไม่ใช้รูปภาพ

ถ้ายังไม่มีรูป หน้าเว็บจะแสดงพื้นหลังไล่สีฟ้าพร้อมชื่อแทนโดยอัตโนมัติ ไม่พังหรือโชว์ไอคอนรูปหาย
